# Bundled fonts

- Inter variable font: https://github.com/google/fonts/tree/main/ofl/inter
- Amiri Regular (Arabic): https://github.com/google/fonts/tree/main/ofl/amiri

Downloaded 4 November 2026 from the Google Fonts repository. Both are distributed under the SIL Open Font License 1.1. Full license and copyright notices accompany each font in `Inter-OFL.txt` and `Amiri-OFL.txt`, and are exposed in Settings → Font & library licenses. No font binaries have been modified. Fonts load from the APK, with no runtime font network request.
